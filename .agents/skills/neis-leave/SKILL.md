# 복무 신청
저장소 루트에서 실행한다. 별도 worktree를 만들지 않는다.

1. 자연어에서 복무 종류, 한국 기준 날짜, 시작·종료 시간, 사유, 개인결재선을 추출한다. “내일 오후 3시부터 조퇴”는 종료 시간·사유·결재선이 누락되어 있으므로 질문한다. 근무 종료 시간을 추정하지 않는다. 연도가 없는 날짜는 확인한다.
2. `src/leave.mjs`의 validateLeave로 검증한다. 단일 날짜만 지원한다. 여러 날 출장은 지원하지 않는다고 설명한다.
3. 현재 실제 나이스 어댑터는 차단되어 있다. 실제 사이트를 임의 탐색하거나 추측한 선택자로 입력하지 않는다. Windows PC와 기관 허용 여부, 사용자 수동 로그인 후 실제 화면 검증이 필요하다.
4. 가상 데이터만 `npm test`로 검사한다. 이 테스트를 실제 나이스 성공으로 보고하지 않는다.
5. 실서비스 구현 시 조회 범위 전체의 기존 신청, 취소/반려 상태, 날짜 겹침을 확인하고 개인결재선의 실제 결재자를 사용자에게 보여 준다. DOM 입력값과 저장 결과를 각각 검증한다.
6. 날짜·시간·사유·결재선을 최종 확인받은 뒤에만 상신한다. 현재 상신 코드는 없다. 변경된 내용에는 이전 승인을 재사용하지 않는다.
7. 오류나 결과 불명확 시 즉시 중단하고 이미 처리되었는지 조회한다. 자동 재상신하지 않는다. 사용자 수동 처리를 안내한다.
8. 결과는 검증 범위, 입력 준비 여부, 승인 대기 여부, 실제 상신 여부, 실패 단계로 보고한다. 인증정보·원문 화면·신청 사유를 로그에 저장하지 않는다.
