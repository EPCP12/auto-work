# 품의 작성 — 구현 대기
목적: 장바구니 기반 품의서 초안 및 결재요청.
현재 이 업무의 Playwright 실행 스크립트는 없다. 실행 성공을 주장하지 말고 개발 대기 상태를 알린다.
실제 화면 확인 전 선택자를 추측하지 않는다. 실패 시 반복 실행하지 않고 중단한다.
학생 정보는 로컬에서 처리하고 외부 AI에 원문 목록을 보내지 않는다.
구현 시 학생 출결은 학생 식별자·날짜·유형·사유와 중복 여부를 확인한다.
품의는 접근 가능한 상품의 규격·수량·단가·합계를 재검산하고 누락값을 질문한다.
검수는 주문 대조 및 사용자의 실제 납품·검수 확인을 필수로 한다.
최종 쓰기 작업 전 구체적인 내용을 보여 주고 승인받는다.
보고 형식: 미구현 기능 / 필요한 입력 / 승인 상태 / 실제 처리 여부.
